11 月 10 日记。咸鱼找人做的那台这个月到货，先把查到的东西记下来，免得到货手忙脚乱。

## 这是什么

HachimoDock，哈基米机，小米技术委创新产品团队孵化的开源桌面 AI 终端，2026 年 10 月 24 日到 25 日在杭州观猹大会上亮相。小米商城不卖这个成品，软件源码在 GitHub 上公开，硬件的 PCB、BOM、结构件模型和装配教程在嘉立创开源广场。

说白了，就是给电脑上的 AI Agent 配个身体。Agent 在电脑里思考、执行、等确认、报错，桌上那只西高地小狗就用表情、动作和会话气泡同步演出来。抬头瞄一眼就知道它跑到哪了，不用一直切回终端。

写这篇时，GitHub 仓库 978 个 star，104 个 fork。桌面客户端最新版 0.1.201，配套设备固件 0.7.103-p4-r181。管理端只提供 macOS Apple silicon 和 Windows x64 安装包，没有 Intel Mac 或 Linux 包。

## 硬件长什么样

- 主控：ESP32-P4，RISC-V 双核，最高 400MHz；32MB Flash + 32MB PSRAM
- 屏幕：2.8 英寸 480×640 MIPI-DSI IPS 竖屏，应用逻辑画布是 640×480，固件旋转输出
- 输入：3 个凯华 BOX 机械键（SW1 / SW2 / SW3）+ 1 个四向中按摇杆，可配 12 种手势
- 音频：板载麦克风 + 2011 小腔体喇叭
- 连接：USB-UART 烧录、日志和日常数据传输；USB 供电，不用配电池
- 早期还试过 Radxa Cubie A7Z 和树莓派 Zero 2W 两个方案，都已废弃，最后收敛到 ESP32-P4 + USB 直连这一条

定位先搞清楚：大模型和语音识别都不在 P4 上跑，全在电脑端。公开安装包也不带任何服务 Key，语音、对话、生成能力都要自己在客户端里填 API 配置。这台设备就是个状态显示器加输入控制器，自己跑不了模型。

## 复刻最容易翻车的几件事

### 芯片 v1 和 v3 不能互刷

完整烧录包分 v1、v3 两个版本，刷错就出问题。开发板型号里的 M，ESP32-P4-WIFI6-M，指的是焊接了排针，不代表芯片修订版，别凭型号猜版本，问清实际芯片版本再选包。微雪 ESP32-P4-Pico v3.2 还有单独的测试版烧录包，也不能用通用 v3 固件覆盖。

### 屏幕排线是 22pin

BOM 栏写的是 15P / 22P DSI，评论区已经有人按链接买了 15p 的屏、对不上板子。另一条回复说主板和屏幕是通过 22pin 线连接的，买屏要跟店家说要 22p 线，找不到就去淘宝找 22pin 0.5mm 间距同向 FFC 线。屏幕排线接的是 DSI，不是 CSI，断电后再插拔。

### PCB 现在是 V1.2

嘉立创页面上原理图是 AAAV1.2、PCB 是 PCB_V1.2。评论区有人问 V1.1 和 V1.2 有什么差别、打成 V1.1 有没有影响，页面上没有作者回复，稳妥起见直接按 V1.2 打。

### 只能换键帽和轴

FAQ 写得很死：键帽、机械键盘轴可以换，其他都不可以。外壳可以拿嘉立创的 3D 文件或拓竹的打印资料去打印，没有 3D 打印机就发给嘉立创 3D 打印或第三方打印服务，一套外壳几十块。

## 到货验收清单

我这台是咸鱼找人做的，到货按这张单子验收，缺一项都不算交付完成：

1. 芯片版本：卖家报出实际的 v1 / v3，确认刷的是 R181 对应包，不是混刷
2. 板子型号：ESP32-P4-WIFI6 还是 WIFI6-M，还是 Pico，实物与约定一致
3. 屏幕：22pin 排线，点亮后宠物动画能动，没有花屏
4. 输入输出：SW1 / SW2 / SW3 三个键 + 摇杆四个方向 + 中按都有反应，麦克风能录、喇叭能响
5. 联机：连上 Pet Manager 客户端能识别设备、显示固件版本，USB 冷启动不断连

README 自己也留了口子：v3 的 24MHz 显示修复已在实机确认恢复了宠物动画，但按键、麦克风、完整形象与固件传输这些还写着仍需实机验收，先在测试设备上验证再当主力用。

## 到货后玩法，按优先级排

### 1. Agent 状态跟随

适配 ChatGPT（Codex）、Claude、OpenClaw、MiMoCode、WorkBuddy 和 DeepSeek Harness。思考、执行、等待确认、完成、报错都会变成小狗的表情动作 + 会话气泡，完成或出错后气泡还会停留约 60 秒。


这是我最期待的一点。Claude Code 跑长任务时，不用反复切终端确认它是不是卡在等确认上。不过有两个限制：检测到程序不代表它的输入框已可用；切 WorkBuddy 的设备气泡，不代表电脑上的 WorkBuddy 对话也会自动切过去。不同 Agent 的适配完整程度不一样。

### 2. 语音派活

按住 SW1 说话，松开出草稿，短按确认才发送；SW2 长按开始 / 结束实时对话；SW2 短按切换宠物页面与组件中心；SW3 短按返回或取消；摇杆用来选会话、组件或执行组件动作。

官方举的例子是“帮我分类整理下电脑桌面的文件，并换一张好看的壁纸”，对着小狗说一句，电脑上的 Agent 接手干。语音确认发送不等于批准 Agent 的工具权限请求，敏感操作还是要回电脑端确认。

### 3. PetUI 自制组件

内置 29 个组件，组件中心直接预览、同步、移除。现成的有自选股行情、敲木鱼、近期待办、电脑状态、番茄钟、喝水提醒、天气、黄历、电台、每日资讯、Token 用量仪表盘；游戏有贪吃蛇、迷宫、接球、切水果、五子棋、电子宠物、转盘、抽签、抛硬币、塔罗牌。

玩法是：在 Claude 或 Codex 里调 `petui` Skill，用自然语言描述想要的游戏或工具，它会生成 `.clawpkg` 组件包，校验通过后发布到本地组件库，再由桌面端经 USB 同步到设备，不用重启就能热加载。设备跑的是声明式有界运行时，每个组件有严格的存储与资源配额，离线校验通过不等于实机能跑，得按设备实际报告的能力来。

结合我自己的东西，到货后我想先做三个：NAS / 软路由状态小屏、Claude + Codex 的 Token 仪表盘、杭州天气 + 每日热点简报。实时数据要走 PC 端已实现的数据源，别假装任意接口都能用。

### 4. 换形象

默认是西高地小狗，支持导入照片 / 视频、AI 生成、社区导入。宠物照片、情侣照片、卡通角色都可以做搭子素材。键帽和外壳也能自己打印换色，机身配色可以跟屏幕角色搭配。

### 5. 米家 MiLoCo 联动

在桌面管理端授权米家账号后，可以用语音控制家里的设备，小屏切到家居控制台看设备状态、灯光控制和监控画面。但这条链路是电脑端对接 MiLoCo，不是 P4 自己加入米家网络，具体支持哪些设备要看账号授权、模型和服务条件。家里有米家设备的话，这个可以排在 Agent 跟随之后第二个试。

### 6. 当副屏、收音机、小游戏机

电台组件能听不同城市的节目，每日资讯能播报，碎片时间就当个贪吃蛇、敲木鱼的解压玩具。官方自己归纳的等价形态也是这几个：一支快捷语音输入麦克风、一台小游戏机、一部 FM 收音机、一块看 AI 任务进展与电脑状态的桌面副屏、一个联动智能家居的桌面中控。
